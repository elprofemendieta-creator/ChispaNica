# 🇳🇮 ChispaNica

### Juega · Aprende · Gana · Compra

**ChispaNica** es una plataforma digital nicaragüense que combina gamificación, aprendizaje, entretenimiento, recompensas, servicios digitales y, progresivamente, comercio electrónico.

La idea central es crear una plataforma a la que las personas quieran **regresar diariamente**, no solamente entrar cuando necesiten comprar algo.

---

# 🎯 VISIÓN DEL PROYECTO

Crear un ecosistema digital donde el usuario pueda:

* 🎮 Jugar.
* 🎓 Aprender.
* 🪙 Ganar monedas.
* 💎 Conseguir diamantes.
* 🔥 Mantener rachas.
* 🏆 Subir de nivel.
* 🎁 Obtener recompensas.
* 🛍️ Comprar productos.
* 💻 Contratar servicios digitales.
* 📚 Acceder a cursos.
* 👥 Participar en una comunidad.
* 🤝 Recomendar ChispaNica y obtener beneficios.

El proyecto debe crecer **por fases**, evitando construir funcionalidades innecesarias antes de validar que los usuarios realmente utilizan la plataforma.

---

# 💡 CONCEPTO PRINCIPAL

ChispaNica no debe sentirse inicialmente como una tienda.

Debe sentirse como una plataforma de entretenimiento y recompensas que posteriormente incorpora comercio y servicios.

La experiencia buscada es:

> **"Entro a jugar → gano → progreso → regreso → descubro algo nuevo → eventualmente compro."**

---

# 🧠 PRINCIPIOS DEL PROYECTO

## 1. Primero atraer, después vender

La página inicial debe despertar curiosidad antes de pedir registro o compra.

El visitante debe poder explorar parte del contenido sin crear una cuenta.

El registro será necesario para:

* Guardar monedas.
* Mantener rachas.
* Participar en determinados juegos.
* Subir de nivel.
* Obtener recompensas.
* Participar en promociones.

---

## 2. No saturar al usuario

ChispaNica NO debe convertirse en una página llena de anuncios.

Las promociones deben aparecer estratégicamente.

Evitar:

* Pop-ups constantes.
* Anuncios invasivos.
* Ventanas que bloqueen la navegación.
* Mensajes repetitivos.
* Notificaciones excesivas.

La publicidad debe complementar la experiencia y no destruirla.

# 🪙 ECONOMÍA VIRTUAL

ChispaNica utilizará dos tipos principales de recompensas:

## 🪙 MONEDAS

Las monedas serán la recompensa común.

Valor de referencia:

**100 monedas = C$1**

Ejemplos:

| Monedas | Valor de referencia |
| ------: | ------------------: |
|     100 |                 C$1 |
|     300 |                 C$3 |
|     500 |                 C$5 |
|   1,000 |                C$10 |
|   5,000 |                C$50 |
|  10,000 |               C$100 |

La equivalencia puede modificarse posteriormente desde el panel administrativo.

### Importante

Las monedas NO deben considerarse dinero en efectivo.

Son una moneda virtual interna utilizada para promociones, descuentos, juegos y recompensas según las reglas de ChispaNica.

---

# 💎 DIAMANTES

Los diamantes deben ser más escasos que las monedas.

Se utilizarán para:

* Recompensas especiales.
* Promociones.
* Eventos.
* Descuentos especiales.
* Beneficios premium.
* Juegos especiales.

Los diamantes pueden obtenerse mediante determinadas actividades y también mediante conversión de monedas.

Ejemplo inicial:

|     Conversión |    Resultado |
| -------------: | -----------: |
|  1,000 monedas |   1 diamante |
|  5,000 monedas |  6 diamantes |
| 10,000 monedas | 15 diamantes |

Estos valores son configurables.

---

# 🔥 SISTEMA DE RACHA

La racha recompensa al usuario por regresar diariamente.

Ejemplo:

| Día |  Recompensa |
| --: | ----------: |
|   1 |  10 monedas |
|   2 |  20 monedas |
|   3 |  30 monedas |
|   4 |  40 monedas |
|   5 |  50 monedas |
|   6 |  60 monedas |
|   7 | 100 monedas |

Al completar 30 días consecutivos:

* 300 monedas.
* 1 diamante.
* Insignia especial.

La recompensa de 30 días debe poder modificarse desde administración.

# 🔐 SEGURIDAD ADMINISTRATIVA

Nunca confiar únicamente en botones ocultos en HTML.

La seguridad administrativa debe estar protegida mediante:

* Autenticación.
* Roles.
* Supabase Row Level Security (RLS).
* Políticas de acceso.
* Validación en servidor/base de datos.

Un usuario normal nunca debe poder modificar directamente:

* Sus monedas.
* Sus diamantes.
* Su nivel.
* Su racha.
* Sus recompensas.
